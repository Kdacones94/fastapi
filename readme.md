# FastAPI Log Processor for Neo4j

## Scope

This project focuses on providing an API to process log files and store the extracted data in a Neo4j graph database. The primary objectives include:

- Parsing and processing log files.
- Storing and managing data in Neo4j using a Python-based ORM.

## Future Goals

While not currently in scope, the project has ambitious plans for future development, including:

- Mapping processed event log data to the MITRE ATT&CK framework to visualize relationships and enhance threat analysis.
- Implementing recommendation systems to suggest solutions based on identified threats.
- Incorporating data science techniques to identify false positives and analyze rogue processes for improved accuracy and insights.

These features are planned for later phases and are not part of the initial project scope.
